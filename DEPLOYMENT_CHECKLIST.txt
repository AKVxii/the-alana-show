ALANA — ALL OVER THE PLACE — GITHUB / VERCEL DEPLOYMENT

1. Keep the live production website on the main branch.
2. Build and review redesign work on luxury-redesign or on a dedicated feature branch created from luxury-redesign.
3. Never commit redesign work directly to main.
4. Open an initial review pull request with luxury-redesign as the base branch.
5. Review the resulting Vercel Preview deployment on desktop, desktop at 120% zoom, tablet, and mobile.
6. Test all required integrations before approval.
7. After the redesign is fully approved, use a separate reviewed pull request to merge the completed redesign into main.
8. Production should redeploy only after the approved redesign reaches main.
9. Do not recreate, rename, expose, or delete the existing Vercel environment variables:
   - YOUTUBE_API_KEY
   - RESEND_API_KEY
   - CONTACT_TO_EMAIL
   - CONTACT_FROM_EMAIL
10. After Vercel reports Ready, test:
   - Featured, latest, and recent YouTube content
   - YouTube failure/fallback state
   - Recent-conversation search and keyboard shortcut
   - True Oldies links
   - Every podcast-platform link
   - Contact form delivery
   - Inquiry-prefill links
   - Mobile navigation
   - Keyboard navigation
   - Reduced-motion behavior
   - Desktop, tablet, and mobile presentation

LEGACY FILES

The root-level app.js and styles.css files are retained temporarily as rollback references. The active modular frontend uses src/main.js and src/styles.css. Do not delete the legacy files until the modular site has passed production verification.

FEATURED CONVERSATION

The public heading remains “Featured Conversation.” The YouTube function supplies latest, mostWatched, and recent episode data. The frontend uses mostWatched as the featured selection and retains a polished static fallback when the API is unavailable.

ROLLBACK

Before any future production merge, record the current known-good main commit. If a production problem occurs, restore the previous known-good commit through GitHub rather than making random live-file edits.
