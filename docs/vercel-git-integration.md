# Vercel Git integration

Alana — All Over the Place website uses the following deployment workflow:

- GitHub repository: `AKVxii/the-alana-show`
- Source-of-truth branch: `main`
- Existing Vercel project: `the-alana-show-czu9`
- Pull requests should create protected preview deployments.
- Reviewed merges to `main` should create production deployments automatically.
- Do not import the repository into a second Vercel project; reconnect the existing project if Git authorization is interrupted.

This file was added on August 26, 2026 as a harmless end-to-end verification of the restored GitHub-to-Vercel connection.
